# عالية طويق | Tauwiq Heights — Digital Brochure

نسخة أولى من بروشور عقاري رقمي باللغة العربية، مبني على بيانات ملف Excel المرفق والهوية البصرية للمشروع.

## الهوية
- العنابي: `#633843`
- البيج: `#F4EEE7`
- الكريمي: `#DBD1BB`
- اتجاه الموقع: RTL
- التصميم: Minimal / Editorial

## بيانات المصدر
تمت قراءة ورقة `Database` من ملف `Tuwaiq Heights Project.xlsx`.
- عدد الوحدات ذات السجلات الفعلية: 159
- المواقع: 7
- المتاحة: 84
- المحجوزة: 55
- المباعة: 20
- أنواع الوحدات: 138 دوبلكس، 21 فيلا

### الحقول المعروضة
- رقم الموقع والمبنى ورمز الوحدة
- نوع الوحدة والدور
- المساحة الأساسية والأجزاء الخاصة وإجمالي المساحة
- السعر
- الغرف ودورات المياه والواجهة وعرض الشارع والمصعد والموقف
- حالة الوحدة

لا يتم نشر أعمدة الأسعار الداخلية السابقة أو الخصومات المنفصلة أو السعر المنفذ فعلياً.

## تشغيل محلي
1. فك ضغط المشروع.
2. افتح المجلد في Visual Studio Code.
3. شغّل `index.html` باستخدام Live Server.
4. لا تفتح الصفحة مباشرة بصيغة `file://` لأن المتصفح قد يمنع تحميل ملفات JSON.

## النشر عبر GitHub Pages
1. أنشئ مستودع GitHub.
2. ارفع محتويات هذا المجلد.
3. من Settings ثم Pages اختر النشر من الفرع الرئيسي والمجلد الجذر.
4. انتظر إنشاء رابط GitHub Pages.

## تحديث الوحدات من Excel
استخدم ملف `tauwiq-excel-importer.html` المنفصل:
1. افتح الأداة محلياً في المتصفح.
2. اختر ملف Excel المحدّث.
3. تفحص الأداة ورقة `Database` وتقرأ السجلات التي تحتوي على رقم موقع.
4. تنزّل ملفات `project.json` و`units.json` و`sites.json`.
5. استبدل الملفات المناظرة داخل مجلد `data` في الموقع.
6. ارفع التغييرات إلى GitHub.

**مهم:** GitHub Pages موقع ثابت؛ تعديل Excel وحده لا يحدّث الموقع مباشرة. يجب إعادة توليد ملفات JSON ونشرها. لا توجد قاعدة بيانات أو اتصال بـ SQL Server في هذه النسخة.

## تنبيه قبل النشر العام
الأسعار وحالات الوحدات مأخوذة من ملف Excel المرفق. راجعها واعتمدها من الإدارة قبل النشر العام. لا ترفع ملف Excel الأصلي أو بيانات العملاء أو أي معلومات داخلية إلى مستودع عام.


## تحسينات الواجهة
- تمت إضافة شعار مجموعة عبدالمحسن الرصيص وأبنائه من دليل الهوية.
- تمت إضافة مخطط معماري داخل نافذة تفاصيل كل وحدة، وفق الموقع والمبنى والدور في ملف نماذج الوحدات.
- تم تحسين زر إغلاق نافذة التفاصيل وتنسيق معرض المخططات.
- تمت إضافة صور مخططات مخصصة ضمن `assets/images/plans/`.
- أداة تحديث Excel المرفقة منفصلة عن ملفات الموقع العامة. بعد التحديث تعيد إنشاء بيانات الوحدات مع مسار المخطط.

## ملفات الموقع المنشورة
تحتوي هذه الحزمة على ملفات الموقع العامة وبيانات الوحدات اللازمة لتشغيله. لا تضع ملفات داخلية أو قوائم عملاء أو مستندات غير مخصصة للنشر العام داخل مستودع GitHub العام.


## آخر تحديث للواجهة
- تم استبدال صورة الواجهة بصورة معمارية نظيفة بدون نصوص أو رموز داخل الصورة.
- تم تكبير شعار مجموعة الرصيص وتحسين وضوحه.
- تم تبسيط النصوص العربية واستخدام كلمات سهلة بدون تنوين.

- تم تكبير شعار الشركة وتوحيد أحجام الشعار والنصوص في الهيدر والفوتر.
- تمت إضافة توضيح الدور/الطابق في تفاصيل الوحدة.
- تم استبدال نص الفوتر بملخص أعداد الوحدات المباعة والمحجوزة والمتاحة، ويتحدث من بيانات المشروع.


## صور المخططات داخل تفاصيل الوحدة
- حُذف قسم عرض النماذج العام من الصفحة الرئيسية.
- يظهر المخطط داخل نافذة تفاصيل الوحدة، بعد السعر وقبل جدول المواصفات.
- تم ربط صفحات المخططات بحسب رقم الموقع (البلوك) ورقم المبنى والدور من ملف نماذج الوحدات.
- لا يعرض الموقع مخططاً إذا لم يتوفر تطابق واضح في الملفات، بدلاً من عرض مخطط مبنى آخر.
- في الموقع 6، كتيب النماذج يعرض فللاً بينما ملف Excel يصنف الوحدات كدوبلكس؛ لذلك تركنا المخطط غير مربوط حتى يتم تأكيد المخطط الصحيح.
- أداة Excel المرفقة تستخدم خريطة الربط نفسها عند توليد ملفات JSON الجديدة.


## تحديث لوحة الألوان
تم توحيد ألوان الواجهة مع الهوية المعتمدة:
- العنابي `#633843` لهوية عالية طويق.
- الكريمي `#F4EEE7` والبيج `#DBD1BB` للخلفيات.
- الأخضر الداكن والذهبي لعناصر هوية مجموعة الرصيص.
- تم الإبقاء على ترتيب العناصر والنصوص والأحجام كما هي؛ التعديل على الألوان فقط.


## إظهار الصور والأسعار حسب الحالة
- كل وحدة تعرض صورة عامة معتمدة من المشروع داخل تفاصيلها.
- يظهر مخطط الدور داخل تفاصيل الوحدة عند توفر مخطط مطابق في كتيب النماذج.
- التحقق الحالي من الملفات: 147 وحدة لها مخطط مطابق، و12 وحدة لا يتوفر لها مخطط مطابق في الملفات المرفقة (6 في الموقع 5 و6 في الموقع 6). لا نستخدم مخطط مبنى آخر بديلاً عنها.
- السعر يظهر للوحدات المتاحة فقط. السعر في ملف البيانات العام يكون `null` للوحدات المحجوزة والمباعة، ولا يظهر في بطاقة الوحدة أو نافذة التفاصيل أو معاينة أداة Excel.
- أداة Excel عند الاستيراد الجديد تطبق سياسة إخفاء السعر نفسها.


## اللغة والأرقام
- واجهة العرض وجميع النصوص التشغيلية باللغة العربية.
- الأرقام الظاهرة بالأرقام العربية مثل ١٢٣٤٥٦٧٨٩٠.
- رموز الوحدات تظهر بالعربية مثل أ١ وب٢.
- الأسعار تظهر للوحدات المتاحة فقط.
- تحافظ أداة التحديث على حالة الوحدة ومخططها من النسخة الحالية عند عدم وجود عمود حالة في ملف Excel.
- يمكن إضافة عمود «حالة الوحدة» بعد الأعمدة الحالية بقيم: متاحة، محجوزة، مباعة.


## تحديث معرض الصور
- تمت إزالة قسم بيانات المشروع من الصفحة الرئيسية.
- تمت إضافة معرض صور متحرك يضم الصور العشر المرسلة.
- ينتقل المعرض تلقائياً كل خمس ثوان، مع أزرار تنقل ومصغرات وإيقاف وتشغيل.
- تمت معالجة الصور بصيغة WebP لتقليل حجمها مع الحفاظ على جودتها.


## إصلاحات الواجهة الأخيرة
- تصحيح مسار صورة المشروع داخل تفاصيل الوحدة إلى الامتداد الفعلي `.jpeg`.
- عزل اتجاه أرقام هواتف المبيعات لضمان ظهورها بالترتيب الصحيح داخل الصفحة العربية.
- إعادة تنسيق مواصفات الوحدة كبطاقات واضحة ومتجاوبة مع الشاشات المختلفة.
